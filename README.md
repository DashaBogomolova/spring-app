# Пример Spring-приложения

## Описание
Простейшее приложение для демонстрации работы с **Spring Framework** и **Spring IoC контейнером**.


## Используемые технологии:
* Spring Framework;
* Maven;
* IntelliJ IDEA или Eclipse.

## Структура приложения:
* папки, созданные Maven (**src, main, webapp** и др.);
* конфигурационный файл: **application-context.xml**; 
* класс **TestBean** — пример бина; 
* класс **TestSpring** — для тестирования работы Spring. 


## Как запустить:
Убедиться, что настроен JDK.
Импортировать зависимости Spring в POM-файл.
Создать директории resources и java. 
Настроить конфигурационный файл Spring.
Запустить класс TestSpring. 


## Что делает приложение: 
Демонстрирует создание объекта с помощью Spring и извлечение его из контекста.
